# Calorie Calculation & Daily Nutrition Tracking App

A full-stack web application designed to help users track daily caloric intake, monitor nutrition metrics, and manage dietary goals. Built with Angular on the frontend and Node.js on the backend, the application delivers dynamic data processing with an emphasis on high performance, clean architecture, and a smooth user experience.

---

## 🚀 Architecture & Monorepo Structure

This repository is organized as a unified workspace containing both the client-side and server-side applications:

* **`client/`**: Modern Single Page Application (SPA) built with **Angular 17** and **TypeScript**.
* **`server/`**: Scalable Backend RESTful API developed with **Node.js**, **Express**, and **MongoDB**.

---

## ✨ Key Features

* **Dynamic Calorie & Nutrient Calculation**: Real-time logic for computing daily target calories, macronutrients, and dynamic goal tracking.
* **Optimized Database Operations**: Persistent storage and optimized query execution using MongoDB and Mongoose.
* **Interactive UI**: Responsive user interfaces and daily progress visualizers built with Angular components.
* **REST API Architecture**: Clean and modular backend structure handling business logic, data validation, and route security.

---

## 🛠️ Tech Stack

### Frontend
* **Framework**: Angular 17 (TypeScript)
* **Styling**: SCSS / HTML5 / CSS3
* **State & HTTP**: RxJS, Angular HttpClient

### Backend & Database
* **Environment**: Node.js
* **Framework**: Express.js
* **Database**: MongoDB (Mongoose ODM)
